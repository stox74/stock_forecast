## 3. 가설

모든 회귀·대응비교의 표준오차는 기업·분기 이중 군집이다. 이중 분산이 음수면 한 방향 군집 중 큰 것을 쓴다 (K5 와 같음).

| 가설 | 내용 | 검정 | 채택 기준 |
| --- | --- | --- | --- |
| **H1 드라이버 몫** | \|ln(실적/E)\| < \|ln(실적/E_noM1)\|. E = (M1·B2·TS) 기하평균, E_noM1 = (B2·TS) 기하평균, 같은 기준일 값 | d = e_E - e_noM1 의 평균 < 0 | 중앙값(e_E) < 중앙값(e_noM1), 상수 < 0, **단측 p < 0.05** |
| **H2 원 가설** | CAR[0,+1] (발표일 0일, %) ~ gap_E_vs_B2 의 계수 > 0. gap = ln(E) - ln(B2) | 기울기 | 아래 'H2·H3 판정' |
| **H3 반대 방향** | 같은 회귀의 계수 < 0 | 같은 회귀 | 아래 'H2·H3 판정' |
| **H4a 매매 가능성** | CAR[asof+1, 발표일-1] ~ gap_E_vs_B2 의 계수 > 0. asof 다음 거래일부터 발표 전 거래일까지 (양 끝 포함). 창이 1거래일 미만이면 뺀다 | 기울기 | 계수 > 0, **단측 p < 0.05** |
| **H4b 선반영 여부 (설명용)** | CAR[분기 시작일, asof] ~ gap_E_vs_B2 의 계수 > 0. 분기 시작일은 대상 분기 첫 거래일, asof 는 포함 | 기울기 | 계수 > 0, 단측 p < 0.05. **매매 신호로 쓰지 않는다** (asof 까지의 수익률이라 사후적) |
| **H5 영업이익** | \|OP_hat - OP\| < \|OP_naive - OP\|. 오차 = \|예측 - 실적 OP\| / 최근 4분기(q-4~q-1) 평균 실적 매출 x 100 (%p) | d = e_hat - e_naive 의 평균 < 0 | 중앙값(e_hat) < 중앙값(e_naive), 상수 < 0, **단측 p < 0.05** |

### H2·H3 판정 (둘 중 하나만 채택)

- CAR[0,+1] ~ gap_E_vs_B2 회귀를 **한 번** 돌리고, 계수의 **양측 p** 를 본다.
  - 양측 p < 0.05 이고 계수 > 0 이면 H2 채택, H3 기각
  - 양측 p < 0.05 이고 계수 < 0 이면 H3 채택, H2 기각
  - 양측 p >= 0.05 이면 둘 다 채택하지 않음 ('방향 없음')
- 따라서 같은 자료에서 H2 와 H3 가 함께 채택될 수 없다. 이 판정에는 단측 p 를 쓰지 않는다.
- K5 D2 는 성공 방향 단측이었지만, H2·H3 는 방향을 미리 정하지 않은 가설 쌍이라 양측으로 정한다.

## 4. 판정 시점

- **1차 판정**: 실전 기록 4개 분기(2026Q3~2027Q2)가 쌓였을 때 한 번.
  - 기대 규모는 약 290건이다 (전체 73곳 x 4분기 기준. H1 표본은 driver 급변 제외 60곳 x 4 = 약 240건, H2~H4 표본은 57곳 x 4 = 약 228건).
- **그 전**: 분기마다 기술 통계만 낸다. 기술 통계를 보고 가설·표본·창·기준을 바꾸지 않는다.
  - 기술 통계: 건수, 오차 중앙값, 계수 부호, 3분위 CAR 스프레드
- 1차 판정 뒤 추가 분기는 같은 기준으로 누적 판정한다 (2차 판정 시점은 1차 판정 때 정해 이 문서 변경 기록에 적는다).

## 5. 결과를 보기 전에 정한 사항

- H3·H4a·H4b 는 K5 D2 결과(계수 음수, 3분위 스프레드 10분기 중 9분기 음수)를 보고 만든 가설이다. 그래서 평가 구간(2024Q1~2026Q2)으로는 판정하지 않는다.

- 이상치 제거, 업종별 분할, 다른 창 길이는 1차 판정의 보조 결과로만 내고 채택 여부에 쓰지 않는다.
- 여러 가설을 함께 보지만 다중 비교 보정은 하지 않는다. 대신 이 문서에 적은 가설만 판정한다.
