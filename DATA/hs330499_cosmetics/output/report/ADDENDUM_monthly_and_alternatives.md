# 보론 — 월별 수출자료의 당분기 예측력, 그리고 대안 지표 탐색

본 보고서(FINAL_REPORT.md)에 이어, 다음 두 질문을 추가 검증했다.

> **Q1.** 수출자료는 매월 나오는데, 분기 안에서 월이 쌓일수록 당분기 매출 예측이 좋아지지 않는가?
> **Q2.** HS330499 말고는 도움이 되는 지표가 정말 없는가?

결론부터: **Q1은 부분적으로 '그렇다'(한국화장품제조 매출액 한정, 개선폭 4~6%), Q2는 '330420(눈화장용)이 330499보다 조금 낫다'. 다만 두 결과 모두 위약(placebo) 검정의 잡음 범위를 확실히 벗어나지 못한다.**

---

## Q1. 당분기 수출 '정보 누적 곡선'

분기 Q의 수출자료는 한 번에 나오지 않고 1개월씩 공표된다. 공표시차(익월 15일)를 적용하면 분기 실적 공시(분기 종료 후 45일) 전에 다음 세 시점이 존재한다.

| 이용 개월수 | 확보 시점 | 분기 종료 이전인가 |
|---|---|---|
| 1개월 | 분기 45일째 | 예 |
| 2개월 | 분기 75일째 | **예 (분기 종료 전!)** |
| 3개월 | 분기 종료 +15일 | 아니오 (단, 실적발표 30일 전) |

각 시점의 누적 수출을 **동일 k개월 전년동기와 비교한 YoY**로 만들어 기준모형에 1개만 추가하고, 동일 평가분기(확장창 표본밖)에서 MAE를 비교했다.

### 한국화장품제조 — 매출액 YoY (기준모형 BASE_AR, MAE 18.199, 평가 39분기)

| 지표 | MAE(1개월) | MAE(2개월) | MAE(3개월) | 개선율%(1개월) | 개선율%(2개월) | 개선율%(3개월) |
|---|---|---|---|---|---|---|
| 수출중량 누적1개월 YoY | 17.537 |  |  | 3.64 |  |  |
| 수출중량 누적2개월 YoY |  | 17.147 |  |  | 5.78 |  |
| 수출중량 누적3개월 YoY |  |  | 17.47 |  |  | 4 |
| 수출총액 누적1개월 YoY | 17.946 |  |  | 1.39 |  |  |
| 수출총액 누적2개월 YoY |  | 17.501 |  |  | 3.84 |  |
| 수출총액 누적3개월 YoY |  |  | 17.828 |  |  | 2.04 |

**→ 질문에 대한 답은 '어느 정도 그렇다'이다.** 수출중량 기준으로 1개월 +3.6% → **2개월 +5.8%** → 3개월 +4.0%로, **2개월 누적이 가장 좋다.** 그리고 이 시점은 **분기가 끝나기 전(75일째)** 이므로, 실무적으로는 의미 있는 시점이다.

다만 한계가 분명하다.

- 개선폭 5.8%는 MAE 18.20%p → 17.15%p 로, **매출 증가율 오차가 여전히 17%p**다.
- DM 검정 p=0.86, 예측결합 회귀 λ의 p=0.55 로 **통계적 유의성은 전혀 없다.**
- 3개월(전체)이 2개월보다 나쁜 것은 정보가 늘어서 좋아지는 구조가 아니라 **표본 잡음**임을 시사한다. 정보가 진짜라면 단조 증가해야 한다.

### 영업이익률 · 에이피알

- 003350 **영업이익률**: 1~2개월 누적은 오히려 (-), 3개월에서만 +1.6%. 도움 안 됨.
- 에이피알: **모든 누적개월에서 기준모형(NAIVE)보다 나쁘다** (-71%~-122%). 월별 정보를 아무리 쌓아도 개선되지 않는다.

## Q2. 대안 수출지표 전수 비교

DB(`korea_monthly_trade_data`)에 실재하는 화장품·미용기기 관련 HS를 모두 찾아 동일 프로토콜로 비교했다. 합성계열 3종도 만들었다.

| HS | 품목 | 2025년 수출액 |
|---|---|---|
| 330499 | 기초·색조 화장품 기타 | 85.4억 달러 |
| 3304991000 / 3304992000 / 3304999000 | 330499의 10단위 세분류 | 47.6 / 8.3 / 29.1억 달러 |

| **854370 / 854390** | **미용기기 본체 / 부분품** | **14.6 / 1.8억 달러** |

## Q3. 위약(placebo) 검정 — 그 개선은 진짜인가

에이피알에서 '분기 수출총액 **로그수준**'을 넣으면 매출액 YoY MAE가 25~30% 줄고 예측결합 회귀의 λ가 **p<0.01**로 유의하게 나왔다. 그런데 **샴푸·피부세정제처럼 에이피알 매출과 무관한 품목에서도 똑같이 유의**했다. 그래서 화장품과 전혀 무관한 계열과 **순수 선형 시간추세**를 같은 자리에 넣어 비교했다.

### 에이피알 / 매출액 YoY / 수출총액 로그수준 투입

| 구분 | HS설명 | n_eval | MAE_EXP | MAE_개선_vs_최선기준_pct | encomp_lambda | encomp_p |
|---|---|---|---|---|---|---|
| 실제(화장품) | 화장품 기타 (주 분석대상) | 12 | 8.118 | 24.975 | 1.337 | 0.002 |
| 위약(무관품목) | 반도체 - 기타 메모리 | 12 | 9.603 | 11.246 | 0.978 | 0.005 |
| 실제(화장품) | 샴푸 | 12 | 13.356 | -23.444 | 1.976 | 0.002 |
| 실제(화장품) | 피부세정제 | 12 | 13.997 | -29.367 | 1.265 | 0.001 |
| 위약(순수 시간추세) | 선형 시간추세 | 12 | 16.013 | -47.995 | 1.28 | 0.006 |
| 위약(무관품목) | 반도체 - 기타 집적회로 | 12 | 16.068 | -48.501 | 2.105 | 0.036 |
| 위약(무관품목) | 반도체 - 메모리 | 12 | 16.189 | -49.62 | 1.792 | 0.06 |
| 위약(무관품목) | 석유제품(경질유) | 12 | 16.733 | -54.647 | 1.559 | 0.191 |
| 위약(무관품목) | 승용차(1500~3000cc) | 12 | 18.355 | -69.639 | 5.809 | 0.167 |

**→ 결정적이다. 순수 선형 시간추세만 넣어도 λ=1.28, p=0.006 으로 유의하고, 반도체(854232) 수출은 MAE를 11.2%나 '개선'시킨다.** 즉 에이피알에서 나타난 유의성은 **수출 정보가 아니라 '우상향 추세를 가진 아무 변수나' 넣으면 나오는 현상**이다. 에이피알의 매출 증가율 자체가 추세를 갖고 있기 때문이다. **따라서 에이피알에 대해 HS330499 수출지표가 유용하다는 결론은 기각된다.**

## 실무적 권고

1. **한국화장품제조**에 한해, 분기 75일째 시점에서 `330420 수출총액 YoY`와 `330499 수출중량 2개월누적 YoY`를 **보조 점검지표**로 사용한다. 단독 예측치가 아니라 기준모형 전망의 상·하방 확인용이다.
2. **에이피알**에는 산업 수출지표를 쓰지 않는다. 직전 분기 실적의 관성(NAIVE)이 가장 강한 예측력을 갖는다. 대신 **자사 채널 데이터**(DB의 `apr_us_google_trends`, `apr_us_trends_metrics`, `amazon_bsr_daily`, `amazon_brand_index`)가 훨씬 유망하다.
3. **수준(로그수준) 변수는 쓰지 않는다.** 추세 공행 때문에 허위 유의성을 만든다. 반드시 YoY 등 차분 형태로 쓴다.
4. 새 지표를 시험할 때마다 **위약검정(무관 품목 + 순수 시간추세)을 같이 돌린다.** 본 분석에서 이 절차가 없었다면 에이피알에 대해 잘못된 결론을 낼 뻔했다.
