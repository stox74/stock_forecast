## 💡 실전 팁

### 1. 데이터 준비
- 최소 8개 분기 데이터 필요
- 결측치가 많으면 전처리 필요
- 외생변수(hs_code)는 선택사항

### 2. 대량 처리 시
- 배치 크기: 20-50개 권장
- 메모리: 최소 8GB 권장
- 예상 시간: 티커당 15-20초

### 3. 에러 처리
- `error_log.txt` 파일 확인
- 실패 티커는 별도 재처리
- 데이터 부족이 가장 흔한 원인

### 4. 성능 최적화
- 불필요한 티커 제외
- DB 연결 재사용
- 메모리 모니터링

## 🐛 일반적인 문제 해결

### Q1: "데이터 부족" 에러
**A:** 해당 티커의 분기별 데이터가 8개 미만입니다.
- 더 오래된 데이터 추가
- 또는 해당 티커 제외

### Q2: 특정 모델 예측 실패
**A:** 정상적인 현상입니다.
- 다른 모델로 보완
- 앙상블 예측 활용

### Q3: 메모리 부족
**A:** 한 번에 처리하는 티커 수 줄이기
```python
# 배치 크기를 20개로 제한
example_batch_processing(batch_size=20)
```

### Q4: DB 연결 실패
**A:** DB 정보 확인
```python
# 연결 테스트
from improved_forecast_system import create_db_engine
engine = create_db_engine(db_info)
print("연결 성공!" if engine else "연결 실패")
```
